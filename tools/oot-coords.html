OoT Coordinate Tool

Runs entirely in your browser. Your ROM is never uploaded anywhere.

1. Load your ROM

Waiting for a ROM.

2. Pick a scene

#name (hint)roomsspawnsfloor
Names are hints from memory. Use room/size stats and the map to confirm. Lon Lon Ranch is usually 0x63.

3. View

spawnsactorsdoors
Drag to pan, scroll to zoom. The readout shows coordinates relative to the origin spawn, the same numbers Zombies Mode uses.

4. Place pins (optional layout maker)

Left-click the map to place the pin. Right-click removes the nearest pin.
Zone 0 is where you start. Door cost 0 = open, -1 = no door (e.g. teleporter-only room). Define every zone the map should have; spawns you place replace the defaults for that zone.
pick the "Teleporter destination" tool to set it (Kino-style maps)

5. Export

The layout file goes in the SoH app folder as zombies_lonlon_layout.txt or zombies_kino_layout.txt, then use the menu's "Reload from file". Or send the .json/.png to me.
